ไม่ได้ไลฟ์
กด Play แล้วระบบจะเปิดหน้าต่าง Bot Village ไว้มุมซ้ายบนให้อยู่บนสุดเสมอ แล้วส่งภาพตรงนั้นขึ้นไลฟ์ — อะไรที่ลอยทับหน้าต่างนี้จะติดไปในไลฟ์ด้วย (ย่อ/ปิดหน้าต่างนี้ = ภาพหาย) · กด Stop แล้วหน้าต่างเลิกอยู่บนสุด

ตั้งค่าไลฟ์

Stream Key = รหัสผ่านไลฟ์ของคุณ — เก็บในเครื่องนี้เท่านั้น (state/stream.json) ไม่แสดงกลับบนหน้าเว็บ และถูกลบออกจาก log

เอา Server URL + Stream Key จาก TikTok

  1. บัญชีต้องมีสิทธิ์ไลฟ์ผ่านโปรแกรมภายนอก (TikTok กำหนดเกณฑ์เอง ถ้าไม่มีเมนู Stream Key = ยังไม่ได้สิทธิ์)
  2. บนคอม เปิด tiktok.com → เมนู LIVE / LIVE Producer → ตั้งชื่อไลฟ์ + หมวด → จะได้ Server URL กับ Stream Key
  3. คัดลอกมาวางด้านบน → 💾 บันทึก → กด ▶ Play → กลับไปหน้า TikTok เห็นภาพตัวอย่างแล้วกด Go LIVE (ถ้ามีปุ่ม)
  4. บางบัญชี Stream Key เปลี่ยนทุกครั้งที่สร้างไลฟ์ใหม่ → วาง key ใหม่ทุกรอบ
